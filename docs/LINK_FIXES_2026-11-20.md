# تقرير تصحيح روابط المكتبة — 20 تشرين الثاني 2026

تم فحص الفهرس (279 سجلًا، منها 273 سجلًا فعّالًا قبل التعديل)، وفحص روابط الملفات والأقسام المحلية في صفحات HTML الاثنتي عشرة؛ لم يظهر رابط داخلي مفقود.

## التصحيحات

- نشاط إنكليزي الأول الابتدائي: أُرشف رابط الموزع الذي يحوّل إلى جلسة غير صالحة في بيئة الفحص. يبقى مصدر مناهجنا المتحقق من استجابته متاحًا لنفس كتاب النشاط. صفحة التفاصيل القديمة تعرض البديل بدل كسر الرابط المحفوظ.
- رياضيات الثاني الابتدائي: استُبدل رابط PDF الذي يحوّل إلى صفحة HTML بعنوان صفحة المصدر الفعلي؛ بقي التصنيف «صفحة مصدر».
- روابط Drive الثمانية: إعادة الفحص أكدت توقيع PDF للفيزياء الأول المتوسط ورياضيات الخامس والأول الابتدائي. بقيت خمسة روابط معاينة تعمل، دون تأكيد التنزيل المباشر؛ صُححت تسميتها وأضيف توضيح للمستخدم دون حذف الملفات.
- إعلانات الوزارة الثلاثة: أضيفت روابط بوابة المناهج بديلًا عن تيليجرام في التفاصيل، وأضيف البديلان في مقدمة المكتبة. يبقى الوصف واضحًا بأن الإعلان عن محتوى جزئي وليس كتابًا كاملًا.
- بعد الأرشفة يوجد 272 سجلًا فعّالًا؛ الأرشفة لا تمس الملف الأصلي لدى المصدر.

## حدود التأكيد

- إعلانات تيليجرام وبوابة الوزارة أعادت 403 في بيئة الفحص. إضافة البدائل لا تعني التأكد من إمكانية الوصول إليها عند كل مستخدم؛ لا نستطيع إصلاح خوادم المصدر.
- خمسة ملفات Drive متاحة كصفحات معاينة، لكن تنزيل PDF لم يتأكد. لم نستبدلها بملفات مجهولة أو مختلفة.
- فحص الاستجابة وتوقيع PDF لا يثبت اكتمال المحتوى أو صحة الطبعة أو حقوق إعادة النشر، ولا يضمن قبول AdSense.
- لا تغيير في قاعدة البيانات أو ملفات الإدارة أو التطبيقات أو إعدادات AdSense.

## التحقق

نجح تحقق بنية الفهرس والأغلفة ومسارات الخريطة، وفحص صيغة JavaScript، واختبارات الإحصائيات وتقارير المالك وGoogle، واختبار استعادة فلاتر المكتبة ومسح البحث مع حفظ مصدر الحملة.
