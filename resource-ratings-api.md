# Shared ratings API

Use the existing Taha Android Library Supabase project and publishable/anon key only, never a service-role key. POST `/rest/v1/rpc/taha_resource_rating_summary` with `p_resource` (64-char SHA-256 hex); returns `count`, `average`. POST `/rest/v1/rpc/taha_resource_rating_submit` with `p_resource`, `p_visitor` (persistent random UUID per installation), `p_rating` (integer 1–5), `p_source` (`app` for Android, `website` for web), `p_suggestion` (optional <=300 characters). Same UUID+resource updates rather than increments. Device/browser-based, not verified unique persons; source is client-reported. IDs: SHA-256 of compact UTF-8 JSON string array `[String(grade),type,subject||"",title||"",url||""]` exactly as in `library-data.js`, no slash or Unicode escaping. Interactive lessons use `[grade,"lesson",subject,title,"lessons.html"]`. New references must be added to the database catalog. Never display success before a successful server response. Notes are owner-only; discourage personal information. Android integration requires rebuilding the APK from its source project. Owner reports use authenticated `taha_resource_rating_owner`. Click counts do not verify completed downloads.
