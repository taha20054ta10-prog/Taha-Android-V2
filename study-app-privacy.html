عند إرسال سؤال، يُرسل نصه والصف والمادة إلى خادم المكتبة. لا يحفظ منطق الخدمة نص السؤال في جداول المكتبة. في الإصدار 0.4.0 تعمل المساعدة باسترجاع الشروحات الموجودة، ولا تعمل الإجابات التوليدية أو رفع الصور والملفات. لا تضع معلومات شخصية في السؤال.

English summary

This policy covers the Android app Taha PRO Study Library, package com.taha.educationpro, version 0.4.0. Basic use needs no account. Favorites, reading position, practice results and downloaded PDFs are stored locally. Optional usage measurement is off by default and uses a random installation identifier, estimated installation source, section activity and message-open receipts. Turning it off stops sending and requests deletion of that installation's records.

Submitting a rating sends the stars, reference identifier, optional private feedback and a separate random device identifier. Clearing local app data does not automatically remove server ratings. Study questions are sent with the selected grade and subject to the library retrieval service. Generative AI, image/file uploads and revenue ads are disabled in this version. External publishers and YouTube apply their own policies. The Supabase database project is hosted in Singapore. Contact taha.20054.ta10@gmail.com for privacy and deletion requests.
